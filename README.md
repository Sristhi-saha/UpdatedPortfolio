# ⚡ Sristhi Saha — Modern Developer Portfolio

A sleek, responsive, and minimalist developer portfolio built for **Sristhi Saha** (Frontend Developer & Full-Stack AI Engineer).

Designed with clean typography, light/dark mode theming, an interactive pet companion, dynamic lighting effects, and direct links to live projects and ATS resume.

---

## 🚀 Live Demo & Repository
- **GitHub Repository**: [https://github.com/Sristhi-saha/UpdatedPortfolio](https://github.com/Sristhi-saha/UpdatedPortfolio)
- **Live Deployment**: Ready for Vercel / Netlify / GitHub Pages

---

## ✨ Features

- 🌓 **Adaptive Light & Dark Modes**: Clean contrast, obsidian text, and vibrant cyber gradients in both themes.
- 🐾 **Interactive Cursor Companion (CyberPet)**: Follows mouse cursor with running, sleeping, and petting states (switchable between Fox, Cat, Droid, and Bunny).
- 🔦 **Dynamic Lighting**: Ambient cursor spotlight and tactical flashlight mode.
- 📂 **Featured Projects**:
  - **Zyra AI**: Enterprise-grade autonomous agentic AI platform (NestJS, LangChain, PostgreSQL, RabbitMQ).
  - **MockMate AI**: Google Gemini AI mock interview evaluator with real-time scoring.
  - **AduArchive**: Full-stack MERN academic review and plagiarism detection platform.
- 📄 **ATS-Aligned Resume Hub**:
  - 1-click PDF download with celebratory confetti.
  - In-browser preview in new tab.
  - Quick-print layout.
- 💻 **Interactive Cyber Terminal**: Built-in CLI command interpreter (`help`, `skills`, `projects`, `contact`, etc.).
- 🔊 **Web Audio Synthesizer**: Procedural sci-fi UI clicks and hover tones using native Web Audio API (zero audio file dependencies).

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, PostCSS, Lucide React
- **Audio & Animations**: Web Audio API, Canvas Confetti
- **Deployment**: Vercel / Netlify

---

## 💻 Local Setup & Development

```bash
# 1. Clone repository
git clone https://github.com/Sristhi-saha/UpdatedPortfolio.git

# 2. Enter folder
cd UpdatedPortfolio

# 3. Install dependencies
npm install

# 4. Start local development server
npm run dev

# 5. Build for production
npm run build
```
